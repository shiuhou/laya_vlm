## Separate consequence-use gate

Two abstract interventions, not executable atomic commands. Current drawer state
and desired open/closed state are explicit. Cross both goals, both assignments
of opposite consequences to A/B, and both option orders. Four presentations:

1. Numeric opening changes (-5/+5 mm) in a state-side outcome table.
2. Goal-independent `opening decreases/increases` in that table.
3. The same direction facts attached to candidate-local descriptions.
4. Hypothetical terminal `closed/open` outcomes attached to descriptions.

The fourth is a separate semantic ceiling control, not equivalent in information
or horizon to the +/-5 mm cases. It must not unlock a short-horizon manipulation
reference by itself. No recommended action, score or sorted rank is supplied.
32 fixtures × 2 repeats = 64 calls. Synthetic future facts are explicitly marked;
they are not simulator evidence, perception or a deployable predictor.

To unlock a small **actual-effect** reference test, at least one of presentations
1–3 must solve all eight elementary goal/assignment/order contrasts, stably and
without clipping. This is a finite competence gate, not a statistical threshold.
If none passes, stop the manipulation branch: do not run E0 or tune more prompts.
If it passes, predeclare a separate physical-outcome test before any further calls.

All raw inputs/outputs/logits, source identities, failures and repeats survive.
No weights, thresholds, simulator controls, live interface or source artifacts change.
