# Bounded interface search (not formal E0)

Baseline `0f62862`, 2026-09-23. No runtime policy or candidate gate changes.
Primary question: can a smaller no-effect interface support demonstrably
state-sensitive, interpretable decisions with the installed checkpoint?

First discovery suite, fixed before inference:

- Six explicit command-matching controls with only the request in state.
- Six signed, axis-aligned target displacements (30 mm) and zero displacement.
  Present identical facts as absolute XYZ, relative XYZ, or a spatial sentence.
- Compare compact existing semantics with plain English semantics, and neutral
  option IDs. All eleven native alternatives remain offered; no preferred action,
  candidate ranking or predicted outcome enters state.
- Same local approach objective throughout: minimize nominal target separation,
  retain grip, stop at coincidence. This is a bounded geometric subproblem, not
  the full drawer policy or a claim that loaded actions realize their labels.
- Two identical-input repeats, reverse fixture execution order on repeat two.
  Record full tokens/logits/API outputs. Temperature and weights unchanged.

Discovery permits a separately recorded follow-up only after inspection: test
the smallest promising presentation on held-out magnitudes, multi-axis relations,
option orders and real archived boundaries, or narrow the typed decision if all
eleven-action interfaces fail. Any narrowing changes the research claim; do not
quietly report it as full-task control. Preserve all negative results and count
correlated repeated calls separately from distinct states.

Success requires correct state-dependent changes against an evaluator-only
arithmetic reference, not just probability movement. Archived simulator outcomes
remain an independent physical check. No privileged future effects are included
in this stage's primary conditions. No model choices execute online.

## Follow-up fixed after discovery, before validation calls

Discovery selected spatial sentences + neutral IDs (7/7 axis/zero cases), not a
validated task policy. Validate 12/65 mm signed axes and zero, six mixed-axis
vectors, original/reversed order and cyclically reassigned IDs. Add numeric XYZ
and numeric delta with the same neutral-English candidates to isolate state
presentation from action presentation. Reverse the approach goal to moving away
on six 65 mm axes, without changing state. The expected answer must reverse too.
Project all 18 existing paired boundaries into the selected minimal spatial
interface, for both oracle and perception (36 calls per repeat); independently
score nominal geometry, and use existing physical probes only offline.
These are exploratory validation fixtures, not independent task trials or E0.

## Final bounded diagnostic, fixed after validation

The selected sentence presentation failed all six goal reversals and 17/18
archived oracle geometric labels. Do not promote its axis-aligned success.

Test a narrower supervisory decision, DONE versus CONTINUE: observed cabinet
joint position (numeric) versus articulation category (open/intermediate/closed),
crossed with requested open/close goal. Categories use the installed cabinet's
current-state predicates (qpos < -.14 m is open; qpos > 0 m is closed), not future
effects. Six synthetic combinations, both option orders, and all 18 archived
states under both goals/presentations. This changes vocabulary and temperature
bucket; it can validate a task-progress subdecision, not atomic action selection.

Also test nominal geometric choice with explicit hand-written applicability rules
in candidate descriptions. Compare raw mixed-axis sentences with a deliberately
answer-equivalent dominant-axis projection. The latter already performs the
geometric argmax in code: even perfect scores cannot establish a learned decision
policy or justify silently replacing the original state interface. These are
diagnostic controls for where decision computation occurs. No future effects.

## One targeted extension: goal placement

The final suite's numeric/categorical completion choices largely ignore reversed
goals, while its answer-equivalent geometry control passes 25/25. One untested
confound remains: goals were in the question, not the world-state text. Before
stopping, compare six categorical observed/desired combinations with both fields
in state, as structured values or a sentence, in both option orders. Also move
toward/away intent into state on six axes with a fixed question (both orders).
This is a declared adaptive extension, not a hidden holdout or formal benchmark.
No additional model/prompt search follows this suite in this stage.
