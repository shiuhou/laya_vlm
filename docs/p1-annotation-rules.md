# P1 人工 RGB 標註規則

規則版本：`p1-rgb-annotation-rules/2`。本規則在本輪標註開始前固定；規則檔案的 SHA256 寫入資料包及每份匯出，變更規則必須建立新版本資料包。

## 標註者與輸入

本輪主要人工標註者是專案使用者本人，角色記為 `project_primary_human`。這不是獨立第三方審核，也不宣稱軟體驗證了人的身份。

只根據資料包中原始 RGB 圖像標註。本版不需要深度圖，因此不展示深度。不得先看本輪模型 ROI、推點、候選、分數、幾何判定、軌跡或成功／失敗結果；不得根據這些結果修正標註。身份及「未參照模型輸出」由本人明確聲明，僅記為自我聲明。

同一張圖分別標註以下兩類，不能用其中一類代替另一類。

## A. 抽屜正面可見的潛在推動區域

在 RGB 中圈出可見、朝外、相對平坦的抽屜正面中，可能作為接觸面的部分。

- 排除把手、抽屜內腔、內腔底板、邊框／薄邊／上緣、側板及背景。
- 只標實際可見的像素，不補全被遮擋或看不清的區域。
- 可用多個多邊形表示分離的可見部分；細小窄條可以照實標，不能為了讓幾何演算法通過而加寬、延伸或放大。
- 這只是「視覺上可見的潛在接觸面」標註，不代表機械臂可達、工具放得下、碰撞安全或已通過推動可行性驗證。
- 不能判定該表面是不是抽屜朝外正面時，選 `UNKNOWN`，不要猜測。

## B. 固定柜體參照

圈出視覺上可辨認為同一抽屜所屬固定柜體的參照部分。每個多邊形必須明確選擇類型：

- `FRONT_FRAME`：抽屜開口周圍的固定正面框架。
- `FIXED_EDGE`：可辨認屬於固定柜體的邊緣；圈出其可見像素區域，不把線段任意加粗。
- `ADJACENT_FIXED_BODY`：鄰近、可辨認屬於同一固定柜體的表面。

必須區分同一柜體、畫面背景中的厨房柜子及會隨抽屜移動的部分。桌面不能代替柜體參照。若無法從 RGB 建立「同一柜體且固定」的身份，選 `UNKNOWN`。靜態圖中的這項人工判斷仍不能證明物理上不動，也不能單獨證明已關閉或齊平。

可標多個部分並逐個選類型。對 `UNKNOWN` 可以不畫區域；若圈出有疑問的部分，其類型必須標 `UNKNOWN`，並說明疑問。

## 三種狀態

- `VISIBLE`：能辨認所需部位且存在可見區域；必須至少畫一個多邊形並寫理由。部分遮擋但仍可辨認時，只畫可見部分。
- `UNKNOWN`：遮擋、視角、解析度或身份不明，無法可靠判定／分類；必須寫理由。被完全遮擋以及不確定是否為目標部位都歸入此類。
- `NOT_VISIBLE`：確認此視圖沒有可見的相關部位；不畫多邊形並寫理由。不要用這個狀態隱藏分類不確定性；若原因是遮擋或不能判斷，應選 `UNKNOWN`。

每張圖的兩類都必須明確選狀態、填理由，再保存。多邊形使用原始圖像像素座標，禁止自相交。

## 保存、匯出與評測邊界

可以保存／匯出部分進度，但部分匯出不能進入正式評測或作為模型實驗的人工標籤門檻。全部 50 張圖、兩類標註及本人聲明通過離線驗證後，才算完整標註。

人工標註只供離線評測；不能作為运行策略的目標、ROI、推點或完成條件。`UNKNOWN` 不當作正例或反例，必須單獨報告覆蓋率。請勿為了改善任何模型或幾何結果修改已完成標註；必要更正另存新匯出並說明原因。
