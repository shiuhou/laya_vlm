## Interpretation and stop rule

Report first-repeat counts separately by all four experimental factors; repetitions
are stability checks, not independent observations. Report each physical context,
goal reversal, assignment sensitivity and option order. Only compare probability
magnitudes within the fixed eleven-option bucket. Removal of descriptions also
changes input length/wording; an effect supports presentation interference, not a
specific internal attention or training mechanism.

For the full-effect condition, presented-fact consistency requires direction toward
the requested goal, improvement beyond the stated STOP endpoint, and no stated
obstacle. With true assignment this must exactly equal the independently computed
physical predicate: >0.25 mm absolute AND >0.25 mm STOP-relative progress, with no
new sampled/endpoint obstacle contact. Verify this equivalence on every fixture.

A native, full-effect local reference passes only if every state/goal/order/repeat
is physically supported and the reassigned condition follows its presented facts.
An anonymous-only pass does not validate the native interface. Even a complete
pass supports only this privileged, finite, short-horizon reference and requires
independent validation; it does not validate the no-effect oracle policy or E0.
Reset-envelope flags remain visible and are not waived by local utility.

After this factorial, stop. Do not conduct further prompt search, add state fields,
