# Laya Embodied Intelligence — research handoff

This repository is a portable reading package for continuing the Laya embodied
manipulation research on another machine. It summarizes the research state and
contains selected protocols, findings, evidence summaries, and figures.

**The source research is paused.** This repository does not resume experiments
or replace the source runtime repository. Begin with
[the handoff](docs/HANDOFF.md), then read
[current beliefs](CURRENT_BELIEFS.md) and the
[evidence index](docs/research/research_evidence_index.md).

The package was assembled from source checkpoint
`ea853019d3343ef4cb8eff8a2fdb43a91e760642`, tagged
`research-checkpoint-20260927-paused`. The research baseline was
`b73b5b43dbef29749677fae06b25e94ca27bad87` on `share_main`.

This is a **curated document/evidence package, not a complete experiment
archive**. Raw run directories, full native model traces, model weights, and the
robot simulation environment remain on the original workstation and are not
included here. See `evidence/source_manifest.json` for source paths and SHA-256
hashes of files that were copied.
